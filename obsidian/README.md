# Research vault — read me first

This folder is a real Obsidian vault. Open **Obsidian → Open folder as vault → this folder**
and the [[Capstone - Adaptive Cloud Allocation|capstone note]] will open on the welcome page.

> [!info] What this is
> Sanitized notes about a private university capstone on adaptive cloud autoscaling. No private
> URLs, teammate names, local file paths, or unpublished data live here. Figures are the ones
> cleared for sharing.

## Two rules for friends using this vault

1. If a note says **synthetic**, it is synthetic. Do not quote it as a real-trace result.
2. If a confidence interval overlaps another, the honest sentence is "no proven difference",
   not "roughly equal" and definitely not "ours is better".

> [!tip] Human note
> I kept the mistakes in [[Findings and Changes]] on purpose. A clean result table tells you
> what worked; the mistakes tell you what nearly went wrong. Both are useful.
